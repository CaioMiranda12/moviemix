# Padrões de código

- TypeScript em modo estrito.
- Nomes de arquivos em `kebab-case`, salvo componentes React em `PascalCase`.
- Prettier para formatação; ESLint para verificações estáticas.
- Não inserir credenciais ou tokens no repositório.
- Rotas HTTP não concentram regras complexas de negócio.
- Testes cobrem comportamentos observáveis.
- Alterações funcionais atualizam a documentação no mesmo PR.
