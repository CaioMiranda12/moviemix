# Setup local

1. Instale Node.js 22+ e npm 10+.
2. Execute `npm install` na raiz.
3. Execute `npm run dev:api` em um terminal.
4. Execute `npm run dev:web` em outro terminal.
5. Acesse `http://localhost:5173` e `http://localhost:3333/health`.
6. Execute `npm run lint`, `npm run typecheck`, `npm run test` e `npm run build`.

O banco PostgreSQL e o Docker Compose serão adicionados na issue S0-07.
